More file types, an "AI models" category, the extension on the stores, and a full code audit. Nothing to do on your side: update as usual.

## Install

| System | File |
|---|---|
| Windows 10 / 11 | **`RDM-0.3.12-x64-setup.msi`**, or let RDM install it by itself (the "Version 0.3.12 available" card) |
| Debian / Ubuntu | `rdm_0.3.12-1_amd64.deb`: `sudo apt install ./rdm_*.deb` |
| Fedora / openSUSE | `rdm-0.3.12-1.x86_64.rpm`: `sudo dnf install ./rdm-*.rpm` |
| Linux (others) | `rdm-linux-x64.tar.gz`: extract, then `sh install.sh` |
| Chrome / Edge / Brave / Opera / Vivaldi… | from RDM (the "Browser extension" card), or `rdm-chromium.zip`; Chrome Web Store once reviewed |
| Firefox / Waterfox / LibreWolf… | [addons.mozilla.org](https://addons.mozilla.org/firefox/addon/rdm-rust-download-manager/), from RDM, or `rdm-firefox.xpi` (extension 0.4.8) |

## New

- **AI models** category: `.gguf`, `.safetensors`, `.onnx`, `.ckpt`, `.pt`, `.pth`, `.llamafile`, `.tflite`… with its own folder.
- About 120 more captured formats (video, audio, archives, programs, documents); split ZIP parts (`.z01`…) always captured. A list saved by an older version receives the new formats once.
- RDM accepts the extension installed from the Chrome Web Store.

## Fixed

- An update check with an invalid proxy no longer stays on "Checking".
- The YouTube module goes through the configured proxy.
- Connection counts and checksums are validated again when the list is loaded.
- The sidebar's extension status ends with "…" instead of being cut.

## Under the hood

Eight-pass audit: dependencies, dead code, typed errors, layered architecture with large files split, JavaScript patterns, mutation testing with new readable tests.
