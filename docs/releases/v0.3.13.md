The extension offered when a browser starts, a mini download button, Linux install fixes, security updates of the network and archive libraries. Nothing to do on your side: update as usual.

## Install

| System | File |
|---|---|
| Windows 10 / 11 | **`RDM-0.3.13-x64-setup.msi`**, or let RDM install it by itself (the "Version 0.3.13 available" card) |
| Debian / Ubuntu | `rdm_0.3.13-1_amd64.deb`: `sudo apt install ./rdm_*.deb` |
| Fedora / openSUSE | `rdm-0.3.13-1.x86_64.rpm`: `sudo dnf install ./rdm-*.rpm` |
| Linux (others) | `rdm-linux-x64.tar.gz`: extract, then `sh install.sh` |
| Chrome / Edge / Brave / Opera / Vivaldi… | from RDM (the "Browser extension" card), or `rdm-chromium.zip` |
| Firefox / Waterfox / LibreWolf… | [addons.mozilla.org](https://addons.mozilla.org/firefox/addon/rdm-rust-download-manager/), from RDM, or `rdm-firefox.xpi` (extension 0.4.9) |

## New

- **The extension offered when a browser starts**, as IDM does: a browser starting without the extension gets RDM's offer to install it (a notification with an "Install" button on Linux; RDM's extension window on Windows). Once per browser and session; Settings → Browser → "Offer the extension when a browser starts".
- **Mini download button** (Settings → Browser): the button over videos and 3D models becomes a small icon, without text.
- The extension detects 3D models (glTF/GLB, OBJ, FBX, STL, USD, Gaussian splats, Sketchfab…) and offers to download them.

## Fixed

- Linux: the installer run with `sudo` installed RDM for root, so no menu entry, icon, autostart or tray icon appeared in the user's session. It now goes on as the user (and `install.sh` refuses to run as root).
- Linux: a build folder left owned by root no longer stops the installer (it builds in `~/.cache/rdm-target`).
- KDE Plasma: the menu entry shows at once, without logging out.
- Linux notifications carry RDM's desktop entry: the notification center shows them under RDM, with its icon, and keeps them.
- The project's new address (github.com/fromhumantohorse/rdm) for updates and the Firefox extension's update manifest.
